# Navegación lateral por secciones

Componente SectionDots integrado en Inicio, Tools, Gatherings, Media Club y We Are. Cada página declara destinos con data-scroll-section; el menú incluye únicamente los elementos visibles del diseño de escritorio o móvil. El cálculo usa las posiciones renderizadas, incluyendo la escala de los lienzos existentes.

Punto activo durante el scroll, etiquetas al pasar el cursor o enfocar, botones de 44 px y nombres accesibles. Movimiento suave, inmediato cuando el sistema solicita reducir movimiento. En móvil se reserva un margen lateral de 48 px para los controles. La navegación no altera los hashes usados por GitHub Pages.

TypeScript con tipos explícitos y lint del componente aprobados; demo estática recompilada. Revisión visual e interacción en navegador pendientes. La referencia alaraiz.mx no se pudo recuperar con la herramienta web; se implementó el patrón descrito por el usuario.
