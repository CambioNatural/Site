# We Are All Monsters — vector catalog

20 manually reconstructed reference designs, numbered left-to-right, top-to-bottom. Source: user-supplied preview.jpg. Approximate reconstruction, not recovered original paths. SVGs contain editable named groups and no embedded raster images.

All parts share a 260 × 330 viewBox. Layer order: crown, ears, body, pattern, stripes, mouth, eyes, cheeks. Presets are appearance choices, independent of campaign archetypes.

Edit catalog.ts and run `node --import tsx scripts/export-monsters.ts` to regenerate. The builder additionally supports pupil and palette combinations. This package does not establish ownership or licensing of the supplied reference.
